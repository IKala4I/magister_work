# Знімки для рисунка 4.1

Сюди кладуться знімки екранів для «Рисунок 4.1 – Ключові екрани мобільного застосунку». Конвеєр
(`docs/thesis/docx-pipeline/run_all.sh`) підхоплює їх сам: поки теки порожня, у документі стоїть
плейсхолдер.

- Формат — PNG або JPEG, як зняв телефон; обрізати чи масштабувати не треба.
- Порядок — за назвою файлу, тож назви з номером: `1-today.png`, `2-focus.png`, `3-insights.png`,
  `4-quick-add.png`. До чотирьох у ряд, однакової ширини; п'ять і більше — у кілька рядів.
- Що має бути на екранах (текст плейсхолдера): Today з таймлайном і «скляними» блоками рекомендацій
  різної впевненості та маркуванням «експеримент»; Focus із градієнтним кільцем таймера; Insights із
  теплокартою енергії (година × день тижня) та трендом дотримання; аркуш швидкого додавання задачі з
  природномовним розбором.
- `verify.py` перевіряє, що в документі стоять саме ці файли в цьому порядку (за SHA-256).

Знімки не комітяться (у `.gitignore`): на них можуть бути особисті дані — назви справ, календар.
Коли переконаєшся, що їх немає, додай явно: `git add -f docs/thesis/figures/4.1/*.png`.
